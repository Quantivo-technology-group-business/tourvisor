# Tourvisor

Tourvisor is a comprehensive Booking & Tour Management System based on Laravel, designed for travel websites, marketplaces, travel agencies, tour operators, room/villa rentals, resort rentals, and travel booking platforms.

## Main Features:

1. Laravel Framework
2. Cloud Storage: S3, Google Cloud Storage
3. Multi-Store Marketplace
4. Coupon Modules
5. I18n and l10n localization ready
6. Multiple Payment Gateways
7. Multi-currency Support
8. Mobile App Integration

## Payment Gateways:

1. PayPal Express
2. Stripe Checkout
3. 2Checkout
4. PayPal Pro
5. Flutterwave Payment
6. Razorpay
